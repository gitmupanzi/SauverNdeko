# Icônes communes

`AppIcon` utilise les tracés SVG de **Line Awesome, par Icons8**, sous licence MIT.
Seuls les pictogrammes utilisés sont conservés localement ; aucune police, CDN ou
requête distante n'est nécessaire pour les afficher.

- Source : https://github.com/icons8/line-awesome
- Version source : `124f409a1d954a6e9ec208e2993693f9cd3ffad9`.
- Licence et attribution distribuées : `public/licenses/icons8-line-awesome.txt`.
- Provenance de chaque pictogramme et empreinte du SVG original : `sources.json`.

Les tracés d'origine restent dans un `viewBox="0 0 32 32"`, remplis en
`currentColor`. Les noms sémantiques de l'application et les anciens noms
Bootstrap reçus des API sont résolus par `AppIcon` sans modifier ces API.
Les boutons gardent leur texte ou leur libellé accessible ; l'icône est décorative.
Les logos d'entreprise, avatars et photos métier restent leurs propres images.
