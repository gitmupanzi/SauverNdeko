# Identité de l’entreprise et PDF

Dans **Identité de l’entreprise**, renseignez le nom, l’adresse, le téléphone principal, un téléphone secondaire facultatif, l’e-mail et le site web. Chaque numéro accepte jusqu’à vingt caractères. Le logo peut être choisi depuis un fichier ; le service vérifie l’image et la conserve dans la base après normalisation. Sans logo, le nom de l’entreprise suffit à l’identifier.

Ajoutez les identifiants dont votre entreprise dispose réellement : RCCM, NIF, identification nationale ou autre libellé. Ces dix couples libellé/valeur au maximum restent génériques pour convenir aux pays et secteurs différents. La mention complémentaire est facultative. Aucun numéro, régime fiscal ou texte juridique n’est inventé.

L’entreprise active et les droits de gestion déterminent le profil modifiable. Le compte de plateforme choisit explicitement une entreprise. Un changement de contexte ou une modification concurrente impose de recharger la fiche avant confirmation.

## Présentation des documents

Les bons d’entrée, sortie, livraison et commande, les factures, reçus et avoirs utilisent le profil **courant** de leur entreprise lors de chaque génération. Si vous corrigez son nom ou ses coordonnées, la correction apparaît aussi sur le PDF régénéré d’un document ancien.

Les données du document restent inchangées : tiers émis, numéro, date, articles, quantités, montants et écritures. Les identités antérieures demeurent dans l’historique de la base. Un justificatif ou PDF déjà enregistré est téléchargé tel quel ; il n’est pas remplacé par cette nouvelle présentation.

## En-tête et pied de page

Les deux options sont activées par défaut et enregistrées dans le profil de l’entreprise. Le téléchargement les applique directement, sans fenêtre de choix supplémentaire.

| Option | Présentation |
|---|---|
| En-tête affiché | Logo et identité détaillée en haut du document. |
| En-tête masqué | Présentation compacte ; le nom de l’entreprise reste visible. |
| Pied affiché | Nom, identifiants et mentions courants, avec pagination en bas du document. |
| Pied masqué | Le bas de page est entièrement retiré, y compris sa pagination ; les références métier restent dans le corps. |

Contrôlez l’aperçu après une modification, en particulier avec une adresse longue ou un document multipage. Les fichiers et logos d’une entreprise restent accessibles selon les droits de cette entreprise.
