# Catalogue documentaire ERP

Choisir le document à partir de l’usage et des données disponibles. Le format n’ajoute pas de règle métier ni d’autorisation. Les trois formats suivent la même [charte](charte_documentaire.md).

| Livrable | Contenu utile | Format naturel |
|---|---|---|
| Registre d’articles | Codes, désignations, catégories, unités, stock, seuil, prix et péremption | Excel ; PDF de synthèse si demandé |
| Fiche produit | Identité, stock courant, unité, prix, contrôles et historique autorisé | Word/PDF ; annexe Excel si utile |
| Commande / lignes | Émetteur et tiers autorisés, références, dates, articles, quantités/prix et états | Word/PDF pour le bon ; Excel pour le registre |
| Bon de livraison | Référence de commande, lieu/date et quantités réellement livrées | Word/PDF ; ne pas déduire les livraisons des seules commandes |
| Facture / relevé de règlements | Références source, montants, dates, écritures, cumul et reste distincts | Word/PDF ; détail Excel si demandé |
| Mouvements de stock | Article, commande, type historique, signe, quantité, prix et origine | Excel ; rapport PDF ciblé |
| Audit / alertes / couverture | Population filtrée, dates, unités, écarts et qualifications serveur | Excel ou rapport de pilotage |
| Rapport de direction | Périmètre, constats, mesures utiles et actions proposées | Word/PDF, avec tableaux Excel si nécessaires |
| Note de décision / suivi | Options, décision réellement prise, responsable et avancement | Word/PDF ; registre Excel |
| Document public de services | Produits/structures/professionnels dont la diffusion est autorisée | Word/PDF ou Excel selon l’usage |

Les profils, discussions, données personnelles et audits d’administration ne deviennent pas publics parce qu’ils peuvent être exportés. Les documents comptables, fiscaux ou de paiement utilisent uniquement les champs et gabarits autorisés ; aucune identité ou règle locale n’est inventée.
