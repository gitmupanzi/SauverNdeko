# Faire évoluer SauverNdeko

Le backend actif est Django/DRF ; les tables métier sont conservées dans leurs schémas PostgreSQL et les tables natives Django sont dans public.

Lire les [consignes du projet](../AGENTS.md), puis appliquer le [skill canonique actuel](../sauverndeko-erp/SKILL.md). Ce point d’entrée conserve le nom du skill récupéré depuis GitHub sans dupliquer les instructions maintenues.

Les références et utilitaires de ce dossier décrivent le relevé antérieur à la conversion Django. Ne pas les utiliser comme description du backend installé ni exécuter leurs anciennes commandes Node/Prisma. Consulter les références du skill canonique pour le travail courant.
